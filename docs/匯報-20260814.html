一、Executive Summary（摘要）

OSsysCU 已具備 Master List 報價清單、工程項目 Summary、分判合約編號（MS/C）、地盤付款、糧期／FAC 結算、QS 匯報 PDF 等核心流程。

2.5 已釐清的資料關係（匯報重點）

報價編號（Master List）↔ 分判「項目編號」

本質上是同一套主合約錨點，僅書寫格式不同。

來源欄位示例
Master List報價編號MS/Q1241/24/kp
分判合約 Excel項目編號MS_Q1241_24_kp
工程項目項目代碼／報價編號常與 Master List 相同
MP 合約編號衍生欄Q1241_24（無 MS、序號可能 4 位補零）

結構：MS + Q + 序號 + 年份 + 負責人縮寫
分隔：Master List 用 /；分判表用 _

注意：必須核對 序號 + 年份，不能只看負責人縮寫。

例：MS/C12-7/24/dc 的項目編號 MS_Q2394_24_dc → Master List MS/Q2394/24/dc，不是 MS/Q185/25/jc。

MS/Q185/25/jc 匯入方式（實例）

  • 來源：Ref/2025 Quotation & Contract number.xlsx → 工作表 報價 第 186 行
  • 首次寫入：2026-06-27（2025 年檔批次同步，新增 2375 筆）
  • 後續更新：2026-06-29 再同步
  • 現況：已配對工程項目（project_id=2），負責人 Joseph Chung

五、未來優化路線圖（建議）

Phase 1資料連結與編號統一（短期，1–2 週）

目標：減少「未配對」、避免 MS/C 項目編號指錯報價。

  • 編號正規化服務：統一 MS/Q185/25/jc ↔ MS_Q0185_25_jc ↔ Q0185_25
  • Master List ↔ 項目 一鍵配對（含批量）
  • MS/C 編輯時可搜尋 Master List 報價帶入項目編號
  • staff 去重工具
  • 外判公司 datalist（MS/C + 判項登記）

Phase 2分判商管理（中期，2–4 週）

目標：建立分判商主檔，支援合資格承判商及 MS/C、判項、付款共用。

功能說明
分判商主檔公司中／英名、商業登記、聯絡人、銀行、備註
合資格承判商名冊合格／試用／停用／黑名單；有效期、工程類別限制
下拉取代自由輸入MS/C 外判公司、判項公司名稱、付款登記連動
與 MS/C Ref 同步自 Excel 累積公司名 + 人工維護合併
重複公司合併「文生／俊建」等多写法 → 單一主檔別名
合規提醒選非合格商時提示；過期自動標示

資料表建議：subcontractor_companies + subcontractor_qualifications；現有 subcontractors 加 company_id 外鍵。

Phase 3員工／成員管理（中期，與 Phase 2 並行）

目標：由「負責人名單」升級為可登入的成員系統。

功能說明
成員帳號電郵登入、密碼／SSO（視公司 IT）
角色權限QS／財務／管理員／唯讀（已預留 access_role）
與名單連動項目負責人、負責 QS、MS/C 負責同事均來自同一主檔
離職處理停用後不出現在新下拉，歷史資料保留
Audit log誰在何時改糧期、付款、Master List、ISO 附件
通知（可選）糧期到期、保固金退還、合約會簽未完成
