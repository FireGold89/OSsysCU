### 2.5 已釐清的資料關係（匯報重點）

#### 報價編號（Master List）↔ 分判「項目編號」

**本質上是同一套主合約錨點，僅書寫格式不同：**

| 來源 | 欄位 | 示例 |
|------|------|------|
| Master List | 報價編號 | `MS/Q1241/24/kp` |
| 分判合約 Excel | 項目編號 | `MS_Q1241_24_kp` |
| 工程項目 | 項目代碼／報價編號 | 常與 Master List 相同 |
| MP 合約編號 | 衍生欄 | `Q1241_24`（無 MS、序號可能 4 位補零） |

**結構**：`MS` + `Q` + **序號** + **年份** + **負責人縮寫**  
**分隔**：Master List 用 `/`；分判表用 `_`

**注意**：必須核對 **序號 + 年份**，不能只看負責人縮寫。  
例：`MS/C12-7/24/dc` 的項目編號 `MS_Q2394_24_dc` → Master List **`MS/Q2394/24/dc`**，**不是** `MS/Q185/25/jc`。

#### MS/Q185/25/jc 匯入方式（實例）

- **來源**：`Ref/2025 Quotation & Contract number.xlsx` → 工作表 **報價** 第 186 行  
- **首次寫入**：2026-06-27（2025 年檔批次同步，新增 2375 筆）  
- **後續更新**：2026-06-29 再同步  
- **現況**：已配對工程項目（`project_id=2`），負責人 Joseph Chung

### Phase 2 — 分判商管理（中期，2–4 週）

**目標**：建立 **分判商主檔**，支援合資格承判商及 MS/C、判項、付款共用。

| 功能 | 說明 |
|------|------|
| **分判商主檔** | 公司中／英名、商業登記、聯絡人、銀行、備註 |
| **合資格承判商名冊** | 狀態：合格／試用／停用／黑名單；有效期、工程類別限制 |
| **下拉取代自由輸入** | MS/C「外判公司」、判項「公司名稱」、付款登記連動 |

**資料表建議**：`subcontractor_companies`（主檔）＋ `subcontractor_qualifications`（合格紀錄）
