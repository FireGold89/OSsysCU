5. 分判最終結算 PDF（重點）

已完成 依 QS 澄清：PPT P.16 為準，保留附錄 I／II，結算書本身為 2 頁。

5.1 PDF 頁面結構（每判項）

P1 · 工程帳目總結算（表頭 + 結算表）+ 內部四行簽名
（編制者／合約部／項目部／總經理 + Date）

P2 · 同 P1 工程帳目總結算（表頭 + 結算表）
→ 約 2–3 行 間距（10mm）
→ QS 三段聲明
→ 頁底 美博／分判商雙簽（同附錄 I 格式）

P3 · 附錄 I · VO 明細（有資料或勾選空白附錄時）
P4 · 附錄 II · Contra 明細（同上）

總頁數：2–4 頁（視 VO／Contra 資料而定）

5.2 P2 三段聲明（定稿原文）

分判商同意上述結算所詳列之帳目正確無誤，並不會再就本工程出任何額外要求。

分判商保証日後若因工程質量問題而需作任何維修時，分判商無條件負責維修該等有問題之工程至總承建商滿意為止及賠償因質量問題引致美博工程服務有限公司蒙受之損失或支出。

分判商謹此保證已完全付清所有與上述工程有關工人的全部工資；分判商本人/本公司亦承諾不會再向美博工程服務有限公司根據上述工程作任何索償。

7. 資料關聯說明（2026-09-11 更新）

以下為今日改動涉及模組的存儲表、衍生邏輯與附件路徑。完整 schema 見 docs/Data Model.md。

7.1 實體關係概覽

projects (工程項目) ├── sc_vo_records 變更／扣款（scope 區分主合約 vs 分判） ├── interim_payments 糧期（含 IP Application / IP Cert 附件） ├── subcontractors 分判判項 │ ├── payment_records 分判付款 → 分判 FAC「已付」 │ └── sc_vo_records 配 sc_no → 分判 FAC VO／扣款 ├── projects.fac_* 主合約 FAC 可編欄 + 證書路徑 └── portfolio_projects N 項目總表（分判 FAC 狀態槽 · 與 PDF 未連動） 附件實體：DATA_DIR/uploads/ · DB 存相對路徑
